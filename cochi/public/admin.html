Administración
Cochi.

Gestiona productos, precios, fotos y disponibilidad sin editar código. Para guardar cambios en línea debes configurar Supabase y crear una cuenta administrativa autorizada.

Primero, conecta la nube

Supabase todavía no está configurado. El catálogo público funciona con los datos locales, pero la administración segura necesita el proyecto Supabase.

Abre .env en tu entorno local o añade SUPABASE_URL y SUPABASE_ANON_KEY en las variables de entorno de Vercel. Después ejecuta supabase/schema.sql y supabase/seed.sql en el SQL Editor de Supabase y crea el usuario administrador siguiendo el README.

Entrar al panel

Usa una cuenta que ya exista en Supabase Auth y que esté autorizada en la tabla de administradores. No se crea ni se inventa ninguna contraseña desde esta página.
